Setup and Configuration

  • git init: Initializes a new local Git repository in the current directory.
  • git clone [url]: Creates a working copy of a remote repository.
  • git config: Sets configuration options for your Git installation, such as your username and email.

Basic Snapshotting (Staging and Committing)

  • git status: Displays the state of the working directory and the staging area (which files are untracked, modified, or staged).
  • git add : Stages changes in a specific file for the next commit.
  • git add . or git add -A: Stages all new and modified files in the current directory.
  • git commit -m "[message]": Records the staged snapshot permanently into the project history with a descriptive message.
  • git diff: Shows the differences between unstaged changes in your working directory and the last commit.

Branching and Merging

  • git branch: Lists all local branches in the repository.
  • git branch : Creates a new local branch.
  • git checkout : Switches to a specific branch or commit (can also use git switch in newer Git versions).
  • git checkout -b : Creates a new branch and switches to it simultaneously.
  • git merge : Combines changes from the specified branch into the currently active branch.
  • git rebase: Rewrites commit history by moving a sequence of commits to a new base commit.

Sharing and Updating Projects (Remote Operations)

  • git remote add : Connects your local repository to a remote server.
  • git fetch: Downloads branches and their commits from the remote repository but does not integrate them into your local working branches.
  • git pull: Fetches changes from a remote branch and immediately merges them into your current branch.
  • git push : Uploads your local commits to the remote repository.
